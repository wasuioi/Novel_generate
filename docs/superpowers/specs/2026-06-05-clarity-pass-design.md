# Clarity Pass — ทำให้ผู้ใช้เข้าใจ flow บันทึกตอน & ระบบจำเรื่อง

> วันที่: 2026-06-05 · ที่มา: feedback จาก manao (เพื่อนผู้ทดลองใช้)

## เป้าหมาย

ผู้ใช้งง flow "บันทึกตอน", ระบบจำเรื่อง (lore/ความต่อเนื่อง) และปุ่มอันตราย
เพราะ **ป้ายเป็นภาษาอังกฤษ + ระบบมองไม่เห็น** — ไม่ใช่เพราะเว็บทำงานผิด

แก้ด้วยการเปลี่ยน **"คำ + ป้าย"** และ **ลดปุ่มที่ทำให้สับสน**
→ ไม่แตะ logic หลัก ไม่แตะโครงสร้างข้อมูล ไม่มี migration → ความเสี่ยงต่ำ

## หลักที่ยึด

- เปลี่ยนข้อความ/ป้ายเป็นหลัก ไม่แตะ data model
- **ลบ Skip review ทิ้ง** — ลดความซับซ้อน (ใครไม่อยากเก็บ lore ก็แค่เอาติ๊กออก ได้ผลเหมือนกัน)
- **One Thing at a Time**: การแยก model/temperature/words ออกจาก drawer = **Step 2** (ไม่อยู่ใน PR นี้)

### 1. `components/ReviewPanel.tsx` — อธิบายระบบจำเรื่อง + ลบ skip

|---|---|
| หัวข้อ "Review chapter before saving" | **ตรวจก่อนบันทึกตอน** |
| หัวข้อ "Review updated chapter" | **ตรวจตอนที่แก้ไข** |
| _(เพิ่มบรรทัดใต้หัวข้อ)_ | _AI ช่วยสรุปตอนนี้ และจดข้อมูลสำคัญไว้ ให้ตอนต่อ ๆ ไปเขียนได้ต่อเนื่อง — ตรวจแล้วกดยืนยันได้เลย_ |
| "Summary" | **สรุปตอนนี้** |
| _(เพิ่ม helper)_ | _ความจำย่อ ๆ ของตอนนี้ ใช้ตอนเขียนตอนถัดไป (แก้ได้)_ |
| "Summarizing…" | **กำลังสรุป…** |
| "Retry summary" | **ลองสรุปใหม่** |

| "New lore" | **ข้อมูลใหม่** |
| _(เพิ่ม helper)_ | _AI ดึงข้อมูลสำคัญจากตอนนี้ (ชื่อตัวละคร สถานที่ ปมเรื่อง) · ติ๊ก = ให้ AI จำไว้ใช้ตอนต่อไป / เอาติ๊กออก = ไม่เก็บ_ |
| "Extracting…" | **กำลังดึงข้อมูล…** |
| "Retry lore" | **ลองดึงใหม่** |

| "No new lore extracted." | **ไม่มีข้อมูลใหม่จากตอนนี้** |
| ปุ่ม "Approve & save" | **ยืนยันบันทึก** |
| ปุ่ม "Save chapter & summary" (ตอนแก้ไข) | **บันทึกการแก้ไข** |
| ปุ่ม "Skip review & save chapter only" | ❌ **ลบทิ้ง** (ลบ prop `onSkip` ด้วย) |
| "Cancel" | **ยกเลิก** |

### 2. `components/ChapterWorkspace.tsx`

- ปุ่ม "Send to Chapter History" → **บันทึกตอน**

- **Auto-scroll** _(optional — ตัดออกได้)_: พอกด "บันทึกตอน" แล้ว review panel เปิด ให้เลื่อนจอไปที่ panel อัตโนมัติ → แก้อาการ "กดแล้วไม่เห็นมีอะไรเกิด"

## นอกขอบเขต (Step 2 — ทำภายหลัง)

- แยก model / temperature / words ออกมาเป็นแถบเลือกเหนือปุ่ม Generate
- temperature เป็นภาษาคน (ปลอดภัย / สมดุล / กล้าทดลอง) แทนตัวเลข

## Testing

- `npm run typecheck` + `npm run test` ต้องผ่าน
- เช็กว่าไม่มี test / โค้ดอื่นอ้างถึง `onSkip` ที่ลบไป
- ทดสอบบน browser: กดบันทึกตอน → review โผล่ + เลื่อนไปหา · ยืนยันบันทึก save ได้ · ติ๊ก/เอาออก lore ทำงาน · ถังขยะ confirm ไทย · gear เห็นคำว่าตั้งค่า

## ความเสี่ยง

ต่ำ — เปลี่ยนข้อความเป็นหลัก จุดเดียวที่แตะ logic คือ **ลบ `onSkip`**
ปลอดภัยเพราะปุ่ม "ยืนยันบันทึก" ครอบคลุมแล้ว (ไม่อยากเก็บ lore = เอาติ๊กออกให้หมด)
